# Fire Scout Planning Safe 2.1.10

本版基于本次上传源码，针对四号无人机在长隔墙前长时间等待绕行，以及新路线出现后仍执行旧脱困动作的问题，优化搜索续跑和规划/恢复交接。

长距离受阻时增加稀疏搜索网格，碰撞检查仍使用原细地图和完整机体包络，窄门保留细网格/三维搜索。地图变化时剪除受影响的搜索分支并重开边界，保留其余已探索节点；不再因普通地图更新清空整个搜索。

没有路线但净空充足、规划仍在搜索时保持悬停；确需脱困时优先增加净空。新路线有经碰撞检查的接回段后先刹停旧脱困，再通过自由空间、玻璃风险和稳定性检查接管。受阻旧路径的临时保留段提前留出运行余量。

保留此前路径继承、平滑连接、曲率/动力学限速、机间安全、0.05 秒目标路线检查周期、多机起飞展开和轻量日志工具。安装、参数、诊断和复测命令见 [2.1.10 使用说明](docs/V2_1_10_INCREMENTAL_DETOUR_ZH.md)。历史说明只用于版本追溯。

这是完整 ROS 2 Humble/PX4 节点源码包，需要在你的工作空间中编译。36 项便携回归检查通过，结果见 `docs/v2_1_10_validation.json`；当前环境未进行完整 ROS 2 构建或 PX4/Gazebo 多机联仿。
